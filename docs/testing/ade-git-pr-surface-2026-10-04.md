## Orchestra adaptation and deliberate differences

Git is a contextual workspace tools pane alongside native chat. The header exposes the registered project directory and actual current branch; selecting a sidebar worktree is not itself a checkout operation. The tools maximize/restore control also remains available inside the PR overlay. Git tabs scroll on narrow panes rather than pushing controls outside the split.

PR review presents Summary, Timeline and Code with a compact header. Summary links only tasks in the same project with the same branch. Code separates diffs, displays binary/rename-only changes explicitly, filters files, supports split/unified presentation and places conversations below the matching file. Replies are grouped using GitHub's reply identity. Missing current-line anchors are labelled outdated. The UI does not claim resolved status or offer nonfunctional reply/resolve/fix controls.

Viewed marks use local device storage scoped by backend, project, PR URL/number and immutable base/head pair. Changing either commit clears the visible marks through a new scope. Storage write failures are visible. Deliberate deviation from T3: marks are not yet server-backed/cross-device and there is no optimistic network reconciliation protocol.

Timeline uses actual PR opening metadata, submitted reviews, code comments and confirmed merged state. It explicitly describes its limited event coverage; general discussion, commits, checks, label changes and other hosted timeline events require GitHub. Comment/review reads page over the existing project endpoints, bounded by a 30-second deadline, 2 MiB per page and 20 pages. A failed later page or exhausted budget fails visibly; no partial discussion is presented as complete. Pagination constructs only the same trusted API endpoint rather than following arbitrary token-bearing Link URLs.

Branch creation sends the selected start point in one Git operation. A failed create no longer first checks out the base branch, which previously stranded the user's directory on a different branch. Explicit user checkout remains available separately.
